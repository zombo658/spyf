# GeoWalker

Android-приложение для подмены геолокации: ставишь на карте Яндекса точки-«подъезды»,
задаёшь тайминг — и приложение само прогоняет фейковый GPS по маршруту, «заходя»
в каждый подъезд в нужное время. Работает в фоне через штатный механизм Android
**mock location** (root не нужен).

> ⚠️ **Честное предупреждение.** Подмена GPS почти всегда нарушает правила
> гео-игр и подобных сервисов. У многих есть античит, который детектит mock
> location и **банит аккаунт**. Приложение использует стандартный механизм Android
> и никак не прячется от античита — используй на свой риск и только там, где это
> допустимо (тесты своих приложений, игры без запрета на mock, приватность).

## Что умеет

- Карта Яндекса (Yandex MapKit) с постановкой точек тапом.
- Точки-«подъезды» с порядком прохождения и линией маршрута.
- Тайминг: интервал между подъездами, «стоянка» на точке (имитация захода),
  запуск сразу или в заданное время, режим «по кругу».
- Foreground-сервис: прогон продолжается, когда экран выключен.
- Уведомление со статусом («иду к подъезду 3/8») и кнопкой «Стоп».

## Сборка

Нужны **Android Studio** (или Android SDK) и **ключ Yandex MapKit**.

1. **Ключ MapKit** — бесплатно на
   <https://developer.tech.yandex.ru/services/> → *MapKit Mobile SDK*.
2. Скопируй `local.properties.example` в `local.properties` и впиши:
   ```
   sdk.dir=/путь/к/Android/Sdk
   YANDEX_MAPKIT_API_KEY=твой_ключ
   ```
   (файл `local.properties` в git не попадает).
3. Собери:
   ```
   ./gradlew assembleDebug
   ```
   APK появится в `app/build/outputs/apk/debug/`.

Версии: AGP 8.5.2, Gradle 8.7, Kotlin 1.9.24, compileSdk 34, minSdk 24.

## Как включить mock location на телефоне

1. **Настройки → О телефоне** → 7 раз тапни по «Номер сборки» — включатся
   «Для разработчиков».
2. **Настройки → Для разработчиков → Приложение для фиктивных местоположений**
   → выбери **GeoWalker**.
3. Дай приложению разрешение на геолокацию и уведомления.

Кнопка «Настройки разработчика (mock location)» в приложении открывает нужный
раздел. Если приложение не выбрано как mock — сервис покажет подсказку и не
стартует.

## Как пользоваться

1. Нажми **«Добавлять подъезды»** и натыкай точки по карте (или долгий тап —
   добавляет точку в любом режиме).
2. Задай **интервал** (мин между подъездами) и **стоянку** (сек на точке).
3. По желанию — **время старта** и режим **«по кругу»**.
4. **СТАРТ**. Приложение начнёт отдавать фейковые координаты по маршруту;
   в фоне — через уведомление. **СТОП** — остановить.

Маршрут сохраняется между запусками.

## Как это устроено

- `MockLocationProvider` — обёртка над `LocationManager.addTestProvider` /
  `setTestProviderLocation`.
- `RouteEngine` — детерминированно считает позицию на маршруте по времени от
  старта (приход к точке к её `atMinute`, стоянка, движение к следующей).
- `MockLocationService` — foreground-сервис, раз в секунду проталкивает
  локацию (с лёгким шумом, чтобы трек не был идеально прямым).
- `MainActivity` — карта Яндекса, редактор точек, настройки тайминга.

## Структура

```
app/src/main/java/com/spyf/geowalker/
  MainActivity.kt          UI: карта, точки, тайминг
  MockLocationService.kt   фоновый прогон
  MockLocationProvider.kt  штатный mock location
  RouteEngine.kt           интерполяция позиции по времени
  Geo.kt                   геометрия (дистанция/азимут/lerp)
  Waypoint.kt / Route      модель данных
  RouteStore.kt            сохранение (SharedPreferences + JSON)
  WaypointAdapter.kt       список подъездов
```
